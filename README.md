# MyCloud Learn Lab — 나만의 AWS 디지털 트윈

AWS 콘솔의 클릭 흐름을 그대로 따라 하며 네트워크부터 EKS · 데이터베이스 · 모니터링까지 직접 구성해 보는 개인 실습용 웹 서비스입니다.

## 서비스를 만든 목적

- **이론과 실습 사이의 간극 줄이기** — 수업에서 배운 AWS 개념을 실제 콘솔처럼 생긴 화면에서 직접 눌러보며 익히기 위해 만들었습니다.
- **비용·계정 부담 없는 반복 연습** — 실제 AWS 계정이나 과금 없이, 리소스를 만들고 지우는 과정을 몇 번이고 반복할 수 있습니다.
- **강의 흐름 반영** — AWS Cloud Essentials와 EC2 / VPC / Storage / EKS 워크숍에서 다룬 내용(라우팅, NAT, 보안 그룹 체이닝, 로드 밸런서, Auto Scaling, S3 정적 호스팅, Multi-AZ, IAM 정책 평가 등)을 화면과 규칙에 녹였습니다.
- **살아 있는 인프라 체험** — 만든 리소스가 실시간 아키텍처 다이어그램에 그려지고, CPU · 메모리 · 요청 수 지표가 시뮬레이션으로 계속 움직이며 Auto Scaling과 경보가 그에 맞춰 반응합니다.

## 할 수 있는 것

| 메뉴 | 내용 |
|---|---|
| **실시간 트래픽** | 아키텍처 다이어그램의 선을 따라 요청 · 응답이 점으로 움직입니다. 리소스가 없으면 트래픽도 없고, 만든 리소스에 따라 흐름이 달라집니다: Route 53 DNS 조회, CloudFront 캐시 적중 시 엣지에서 바로 응답, ALB가 정상 대상에게만 전달(정상 대상이 없으면 503), 보안 그룹이 80/443을 막으면 차단, ElastiCache 적중/미스 후 RDS 쿼리, S3 읽기·쓰기, NAT를 거친 ECR 이미지 받기(실패 시 ImagePullBackOff), CloudWatch 지표 전송과 경보. 지금 일어나는 일을 한 줄 설명으로 보여 주고, 일시 정지할 수 있습니다. |
| **네트워크** | 서브넷의 퍼블릭/프라이빗 여부를 연결된 라우팅 테이블(`0.0.0.0/0 → IGW` 또는 `→ NAT`)로 실시간 판정합니다. NAT 게이트웨이는 퍼블릭 서브넷에만 만들 수 있고 탄력적 IP를 씁니다. 보안 그룹은 다른 보안 그룹을 소스로 지정(체이닝)할 수 있고, 참조 중이면 삭제가 막힙니다. 네트워크 ACL은 규칙 번호 순으로 평가되는 Stateless 규칙입니다. 가상 프라이빗 게이트웨이 · 고객 게이트웨이 · Site-to-Site VPN과 Direct Connect 연결도 만들 수 있습니다. |
| **컴퓨팅** | 인스턴스 패밀리별 유형, 루트 볼륨, 온디맨드/스팟, IMDSv2, IAM 역할, User Data를 설정해 시작합니다. 인스턴스 스토어 인스턴스는 중지할 수 없는 등 실제 제약을 따릅니다. 시작 템플릿으로 Auto Scaling 그룹을 만들면 원하는 용량을 유지하고, 시뮬레이션된 CPU에 맞춰 확장·축소(쿨다운 포함)합니다. |
| **로드 밸런싱** | ALB는 HTTP/HTTPS(L7), NLB는 TCP/UDP/TLS(L4) 리스너만 허용합니다. 대상의 헬스 체크는 보안 그룹의 포트 허용과 웹 서버(User Data) 유무로 판정되어, 왜 unhealthy인지 바로 확인할 수 있습니다. |
| **EKS · 워크로드** | 클러스터/노드 IAM 역할이 자동으로 준비되고, 노드 유형별 최대 파드 수(VPC CNI)와 노드 용량에 따라 파드가 스케줄링됩니다. ECR에 이미지가 없거나 노드에 ECR 권한 · NAT가 없으면 `ImagePullBackOff`가 납니다. 디플로이먼트 이미지 변경 시 롤링 업데이트가 진행되고, 인그레스는 Load Balancer Controller가 있어야 ALB가 생깁니다. |
| **스토리지** | S3에는 실제 파일이 저장됩니다. 퍼블릭 액세스 차단이 켜져 있으면 공개 버킷 정책이 거부되고, 정적 웹 사이트 호스팅을 켜면 실제로 페이지가 열립니다. 버전 관리(삭제 마커 · 이전 버전 복원), 수명 주기 규칙(Standard-IA는 30일 이상), 암호화(SSE-S3/SSE-KMS)를 설정할 수 있습니다. EFS는 가용 영역마다 하나의 마운트 대상을 둡니다. |
| **데이터베이스** | RDS는 엔진 · 버전 · 인스턴스 클래스를 골라 만들고, Multi-AZ를 켜면 장애 조치(failover)로 기본/대기 AZ가 바뀌는 과정을 볼 수 있습니다. 마스터 비밀번호는 다시 조회되지 않습니다. ElastiCache(Valkey/Redis/Memcached) 클러스터도 만들 수 있습니다. |
| **엣지 · DNS** | CloudFront 배포는 비활성화한 뒤에만 삭제할 수 있고, 캐시 무효화를 요청할 수 있습니다. Route 53에서는 별칭(Alias) 레코드로 ALB · CloudFront를 가리키며, 도메인 최상위(apex)에 CNAME을 만들 수 없는 규칙을 따릅니다. |
| **보안 · IAM** | 사용자(MFA · 액세스 키는 한 번만 표시 · 최대 2개), 신뢰 정책이 있는 역할, JSON 정책을 만들고 연결합니다. 정책 시뮬레이터는 명시적 Deny → Allow → 암묵적 Deny 순서로 평가합니다. |
| **모니터링** | CPU · 메모리 · 요청 수 지표가 리소스 구성에 따라 2초마다 새 값으로 흘러갑니다(1H/6H/24H/7D). 경보는 OK · ALARM · 데이터 부족 상태를 오가며 알림 벨에 표시되고, 환경 점검은 열린 SSH, 공개 버킷, MFA 없는 사용자, 미사용 볼륨 · 탄력적 IP 등을 찾아줍니다. |
| **비용** | 서울 리전 온디맨드 기준 근사치로 리소스별 월 예상 비용을 계산하고, 예산 대비 사용률과 절약 팁을 보여줍니다. |
| **실습 가이드** | 네트워크 기초 → 보안 → EC2 · Auto Scaling → 스토리지 → 트래픽 경로 → EKS → 데이터베이스 → 운영 · 비용 순서의 체크 항목이 만든 리소스를 보고 자동으로 채워집니다. |

공통으로, 다른 리소스가 남아 있는 리소스(VPC, 사용 중인 보안 그룹 · 볼륨, 노드 그룹이 있는 클러스터 등)는 실제 AWS처럼 삭제가 막히고, 생성 · 삭제 중인 리소스는 상태가 자동으로 바뀝니다. 우측 상단 메뉴에서 실습 환경을 초기화할 수 있습니다.

아이콘은 기본적으로 직접 그린 아이콘을 쓰며, [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) 에셋 패키지를 내려받아 `npm run icons -- <zip 경로>`를 실행하면 공식 아이콘으로 바뀝니다. 공식 아이콘은 `public/aws-icons/`에 복사되고 저장소에는 올라가지 않습니다.

## 한계

- 리소스 정보는 `data/db.json` 파일 하나에 저장되는 단순한 구조라 **혼자 연습하는 용도**에 맞춰져 있습니다.
- S3 파일 저장과 정적 웹 호스팅을 빼면, 서버 · DB · 클러스터는 화면과 상태 흐름만 재현한 것으로 실제로 실행되지 않습니다. 지표도 실제 측정값이 아니라 리소스 구성으로 계산한 시뮬레이션입니다.
- 비용은 서울 리전 온디맨드 요금을 단순화한 학습용 근사치이며, 데이터 전송 · 요청 요금은 포함하지 않습니다.
- Lambda · DynamoDB · CloudFormation 같은 서버리스/IaC 서비스는 개념 정리만 있고 실습 화면은 없습니다.
- 여러 AWS 계정, 리전 전환, 실제 kubectl · AWS CLI 연동은 지원하지 않습니다.

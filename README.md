# MyCloud Learn Lab — 나만의 AWS 디지털 트윈

AWS 콘솔의 클릭 흐름을 그대로 따라 하며 VPC · EC2 · S3 · RDS를 만들어보는 개인 실습용 웹 서비스입니다.

## 서비스를 만든 목적

- **이론과 실습 사이의 간극 줄이기** — 수업에서 배운 AWS 개념을 실제 콘솔처럼 생긴 화면에서 직접 눌러보며 익히기 위해 만들었습니다.
- **비용·계정 부담 없는 반복 연습** — 실제 AWS 계정이나 과금 없이, 리소스를 만들고 지우는 과정을 몇 번이고 반복할 수 있습니다.
- **수업 내용 반영** — EC2 / VPC / Storage 워크숍에서 다룬 세부 설정(라우팅, 보안 그룹과 NACL, EBS, 스토리지 클래스 등)을 화면에 녹였습니다.
- **연결 구조 시각화** — 만든 리소스가 서로 어떻게 연결되는지 대시보드 다이어그램으로 바로 확인할 수 있습니다.

## 할 수 있는 것

| 메뉴 | 내용 |
|---|---|
| **VPC** | VPC를 만들면 메인 라우팅 테이블이 자동 생성됩니다. 서브넷은 연결된 라우팅 테이블에 `0.0.0.0/0 → igw` 라우트가 있는지에 따라 퍼블릭/프라이빗이 실시간으로 판정됩니다. |
| **라우팅 테이블** | 라우트 추가·삭제, 서브넷 연결·재연결. 메인 테이블이나 서브넷이 연결된 테이블은 삭제가 막힙니다. |
| **인터넷 게이트웨이** | 생성(분리 상태) → VPC 연결 → 라우트 추가 순서로 퍼블릭 서브넷을 만듭니다. VPC당 1개만 연결할 수 있습니다. |
| **보안 그룹** | 인스턴스 단위 방화벽(Stateful). 인바운드 규칙 추가·개별 삭제. |
| **네트워크 ACL** | 서브넷 단위 방화벽(Stateless). 규칙 번호 순으로 평가되는 인바운드/아웃바운드 허용·거부 규칙. |
| **EC2 인스턴스** | 인스턴스 패밀리별 유형 선택, 루트 볼륨, 온디맨드/스팟, IMDSv2, User Data까지 설정해 시작합니다. `대기 중 → 실행 중` 상태 전환과 퍼블릭 IP 발급, 루트 EBS 볼륨 자동 생성이 일어납니다. |
| **EBS 볼륨** | 생성, 같은 가용 영역의 인스턴스에만 연결, 분리(루트 볼륨 제외), 스냅샷, 삭제(사용 중이면 거부). |
| **S3** | 버킷 생성(이름 규칙 검증), 실제 파일 업로드·다운로드, 스토리지 클래스 선택, 버전 관리, 퍼블릭 액세스 차단(켜져 있으면 URL 접근 시 403). |
| **RDS** | PostgreSQL/MySQL 선택 후 생성하면 `생성 중 → 사용 가능`으로 바뀌고 엔드포인트가 발급됩니다. 마스터 비밀번호는 다시 조회되지 않습니다. |
| **대시보드** | 인터넷 → IGW → VPC → 가용 영역 → 서브넷 → 인스턴스 순의 실시간 다이어그램, 7단계 실습 진행률, 보안·비용 점검(열린 SSH 포트, 퍼블릭 버킷, 미사용 볼륨 등), 최근 활동. |
| **검색** | 이름·ID·리소스 종류로 만든 리소스를 한 번에 찾습니다. |

공통으로, 다른 리소스가 남아 있는 리소스(VPC, 라우팅 테이블, 버킷, 사용 중인 볼륨 등)는 실제 AWS처럼 삭제가 막힙니다.

## 파일 구조

```
mycloud-learn-lab/
├── server.js          ← Express 앱 진입점 (S3 퍼블릭 액세스 차단 처리 포함)
├── lib/
│   ├── store.js       ← data/db.json 읽기/쓰기 (없으면 자동 생성)
│   └── ids.js         ← "vpc-xxxx" 같은 AWS 스타일 ID 생성기
├── routes/
│   ├── vpc.js         ← VPC / 서브넷 / 라우팅 테이블 / 보안 그룹 / 네트워크 ACL / 인터넷 게이트웨이 API
│   ├── ec2.js         ← EC2 인스턴스 + EBS 볼륨 API (상태 자동 전환 포함)
│   ├── s3.js          ← S3 버킷/객체 API (실제 파일 저장)
│   └── rds.js         ← RDS 인스턴스 API
├── data/db.json       ← 만든 리소스 정보 (첫 실행 때 자동 생성, Git 제외)
├── uploads/           ← S3에 올린 실제 파일 (Git 제외)
└── public/
    ├── index.html     ← 헤더 / 내비게이션 / 좌측 메뉴 / 푸터
    ├── style.css      ← 디자인 토큰, 대시보드·다이어그램·반응형 스타일
    └── app.js         ← 화면 전환(라우터)과 모든 화면 렌더링, API 호출
```

## 한계

- 리소스 정보는 `data/db.json` 파일 하나에 저장되는 단순한 구조라 **혼자 연습하는 용도**에 맞춰져 있습니다.
- EC2 · VPC · RDS는 화면과 상태 흐름만 재현한 것으로, 실제 서버나 DB가 뜨지는 않습니다. 실제로 동작하는 것은 S3 파일 저장뿐입니다.
- Kubernetes/EKS, IAM(사용자/권한), CloudWatch 등은 아직 포함되어 있지 않습니다.
